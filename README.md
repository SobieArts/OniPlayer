# OniPlayer
### A Player For FishHeads.

I built this app because I kept forgetting which video I watched last. Maybe I have early Alzheimer's or somthing. Engineering is about solving problems in the laziest way possible — and OniPlayer is the ultimate expression of that. One key, zero brain cells required.  

---

## What it actually does

Got a folder full of tutorials, anime, or workout videos? OniPlayer uses Windows' last-access time to figure out which one you watched last. Press a key, and it plays it — or the next one. No menus, no hassle.

- **Enter** → plays the last watched video (or next one, depending on mode).  
- **→ (right arrow)** → switches focus to `Play Next` / `Play Current` on the highlighted folder.  
- **← →** while on a folder lets you jump to `Play Previous` as well.

That's it. Stop guessing.

## How to use (the lazy way)

1. Download the .exe from the [Releases page](https://github.com/SobieArts/OniPlayer/releases) or build it yourself.  
2. Run it — config files are created next to the .exe.  
3. Add a video folder (press `1`), give it a nickname.  
4. Navigate with **↑/↓**, press **Enter** to play.  
5. Change the global play mode (Current/Next) by pressing `5`.  
6. Exit with `Esc` — everything is saved automatically.

> Keep the .exe and config files together. Create a shortcut if you want it on your desktop.
